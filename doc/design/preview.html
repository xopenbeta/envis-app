9 · Markdown 正文（AI 面板回答）

Light

安装 MySQL 的步骤

先确认端口未被占用，然后执行下面的命令。详细说明见 官方文档。

  • 检查 3306 是否被占用
  • 设置 root 密码
  • 初始化数据目录
如果端口冲突，请先停止占用进程，或改用 3307。
# 初始化数据目录
$MYSQL_HOME/bin/mysqld --initialize-insecure \
  --datadir="/usr/local/var/mysql" \
  --port=3306
if [ $? -eq 0 ]; then
  echo "初始化完成"
fi
字段默认值
端口3306
字符集utf8mb4

列表行层级：标题 text-md（14px / medium / 主文字色），副标题 text-xs（12px / 次要色），二者之间 mt-0.5。关键是标题不能落在正文档上——原来标题 13px（正文档）+ 副标题 12px，只差 1px 且没有档位差，看起来完全同级。卡片标题另从 12px 提到 13px semibold，避免标题比正文还小。

导航栏底部按钮：是主操作，用 text-foreground + 32px 命中区 + 16px 图标；hover:bg-content4，按下 active:bg-pressed。被模仿的 Voxt 那套是「设置侧栏信息图标」的浅灰处理，用在这里会让主操作退到背景里。
